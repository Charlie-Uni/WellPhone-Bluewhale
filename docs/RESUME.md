# 交还后的安全恢复

本轮范围：同一进程中，继续原来授权的一轮任务。用户交还全部相关会话后自动进入只读核对；不重新生成计划、不扩大邮箱范围、不重置步数预算。进程退出或 shell 断连后不自动恢复，需要重新授权。

## 接管和交还

接管先增加 E；有运行任务时停在 DRAINING，取消并等待旧执行结束，把当前事项的写入状态落盘，再读取人工操作前的日历页面，最后开放 HUMAN。整段触摸和文字动作也必须结算。隐藏小窗保持 HUMAN；交还不是隐藏。

交还先撤销文字草稿、清理触摸并等待文字回执，再增加 E。两个会话都回到 AGENT 后，新执行器首先观察 A/B，不启动 App、不发 ACTION_INSERT、不使用旧节点或 Save 票据。缓存的本轮邮件、已完成事项和当前阶段继续使用；旧确认卡和晚到响应失效。

## 分支规则

| 当前页面 / 状态 | 行为 |
| --- | --- |
| 查重或冲突检查时暂停，当前没有内容编辑页 | 重新走读取与冲突检查，保持原授权 |
| 当前事项的编辑页；只有支持的标题/备注变化 | 对照人工操作前页面，核对其他节点未变和来源标记；保留当前字段，本地确认后只点击 Save，再离开、搜索、重开核实 |
| 用户已保存，当前是能核对的事项详情 | 沿用能读回的标题/备注，重新搜索并打开核实，不再保存 |
| Save 已发出或回执未知 | 只查询和核实；不重新授权同一次 Save。若仍是编辑页，请用户先处理 |
| 时间/日期/账号/日历变化、来源标记删除、未知节点/窗口变化、控件树截断 | 保留当前页面和检查点，提示人工处理；不填旧值、不关闭草稿、不继续导航到下一事项 |
| 邮箱仍有未保存的内容，且本轮还需要读邮箱 | 停在恢复提示；邮件已缓存时后续只处理日历，不操作邮箱草稿 |

支持的字段 resourceId 是有限兼容配置，尚未真机验证。恢复要求账号、日历/列表可明确定位；事件日期和时间分别按 start_date/start_time、end_date/end_time（含 event_ 别名）核对。任务要求 task_/reminder_/due_ 的日期、时间字段。页面别处出现旧日期、时间或账号不能代替对应字段的证据。标题/备注导致其他节点或布局变化，也可能保守阻止恢复。搜索框属于任务导航，不按日历内容改动接纳。时间修改可由用户先在 App 保存，再人工核对；本轮不从未知日期选择器猜测新的规范时间。

保存前的确认卡显示当前标题、时间和备注，说明暂停期间其他日程可能变化；确认表示允许保留当前表单内容并保存。确认绑定新 E，Save 票据额外绑定整张页面快照。确认后页面再变化，就停止，绝不再填一遍旧数据。恢复中的查询只允许读取/搜索导航，不允许创建、丢弃或保存。

## 状态和持久化

WorkflowCheckpoint 在内存保留授权范围、已读取邮件、已完成结果与当前事项阶段，不保留模型动作或 Save 票据。内容不进入日志；结束本轮或服务断开丢弃运行上下文。

WriteLedger 增加 HUMAN_HELD：尚未 Save 的已准备事项接管后进入此态，普通重跑只能查询。仅“新页面已核对 + 新确认 + 新票据”可恢复一次保存资格；WRITE_PENDING 接管后成为 UNKNOWN，始终只查。这样首次保存前用户删掉来源标记，也不会让普通重跑立即创建另一个事项。

沿用的标题/备注作为 CanonicalItem.userDraft 持久化，保留原来源、时间和 key；后续去重按新内容核实，避免重新填回旧值。仍需匹配当前授权账号、日历/列表和时区。SQLite 表结构不变，旧 JSON 默认无 userDraft；HUMAN_HELD 是新增枚举，降级到旧 APK 不受支持。

只有离开后重开证据通过才记 VERIFIED。页面不明、确认后变化、保存回执丢失都保留检查点和未知状态；不会为了继续其他事项而离开未保存的人工编辑页。用户可再次接管处理，也可“结束本轮”，之后重新授权。

## 本地验证与设备边界

core 测试覆盖真实工作流的中断、检查点、人工改动持久化、剩余事项继续、去重、Save 未知后查询、不认可伪造证明，以及 Broker 的工作流/输入双排空屏障。

Android 测试使用生产 CalendarGuiPort、GuiNavigator、SessionBroker 和本地存储；模拟 shell、界面树、模型决定和动作回执，检查只读核对、保留字段、新 E/票据、确认后变化和未保存页面保护。窗口按钮测试仍只记录回调，未连通真实 WorkbenchViewModel→Shizuku→App。

真机继续跳过。真实 Gmail/Calendar 字段、保存回执、加载/弹窗、主屏焦点和键盘、进程回收恢复均未验收。最终计数、构建与签名见 [本地检查](../evaluation/LOCAL_CHECKS.md)。
